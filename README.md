# 水利行业规范文本下载器
# 代码来源于：https://github.com/shredderzwj/sl_standard_spider
## 功能
下载
[水利部国际合作与科技司](http://gjkj.mwr.gov.cn/jsjd1/bzcx/)
公开的水利行业标准电子文档。

## 方法

在项目目录运行：

```bash
python run.py
```

PDF 保存到 `standards/pdf/`，SWF 原文件保存到 `standards/swf/`。
再次运行会跳过已有的非空 PDF；网站未提供文件的标准会提示“未解析到下载地址”并继续处理后续标准。
运行日志追加写入 `logs/run.log`（包含时间、下载开始/完成、重试、错误和本轮剩余失败数量），并同步输出到终端。
终端的实时字节进度不会写入日志。

任何条目的地址获取失败、未解析到下载地址、文件下载失败或 SWF 转 PDF 失败，
都会立即写入 `failed_downloads.json`，然后继续下一项。
记录包含标准编号、名称、详情页地址、下载地址（如已获取）、异常类型、失败原因、UTC 时间和累计失败轮数。
同一标准按编号和名称去重；文件通过临时文件加原子替换保存，成功后会从失败清单移除。

只重试失败清单中的条目（不会重新抓取完整标准列表）：

```bash
python run.py --retry-failed
# 加载指定的失败清单，并将剩余失败项写回同一文件
python run.py --retry-failed /path/to/failed_downloads.json
```

重试时先检查本地 PDF，已完成的直接移出清单；其余通过保存的详情页重新获取下载地址。
仅含下载地址的记录也可重试。再次失败会保留并更新记录，全部成功后文件内容为 `[]`。
失败记录缺失或格式错误时会报错退出，不会自动改为全量下载或覆盖损坏记录。

可指定正常下载时的失败记录文件、日志路径和转换分辨率：

```bash
python run.py --failed-file /path/to/failed.json --log-file /path/to/run.log --dpi 150
```

单个文件下载最多尝试 5 次（包含首次），间隔 5 秒；HTTP 4xx 不在本轮自动重试。
地址解析和转换失败本轮不会自动重试，但会写入失败清单供后续重试。
列表页整体获取失败会记录异常并退出，因为此时尚无具体条目信息。
请勿同时启动多个进程写入同一个失败文件。

Linux 下首次使用需赋予转换工具执行权限（仓库已设置此权限）：

```bash
chmod +x bin/swfrender
```

全文公开系统中，推荐性标准可在线阅读，强制性标准可下载使用。
+ 强制性标准可直接解析到PDF文本下载地址，直接下载PDF。
+ 推荐性标准在线阅读系统使用
[FlexPaper](https://flowpaper.com/)
加载swf文件，因此只能抓取到swf文件。这里使用
[swftools](http://www.swftools.org)
的 swfrender 工具将swf渲染成图片，然后再将这些图片合成PDF文档。
